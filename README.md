# SQL Quest

Practice SQL the way it is asked in data-role placement interviews and online assessments in India.

**▶ Start practising: https://omkyao1998.github.io/SQL_Quest_Practise_Portal/**

## What's inside

- **100 SQL questions** in 8 levels: Basics → Aggregation → Joins → Subqueries & CTEs → Window functions → Dates & cleaning → Business cases → Data science SQL
- **40 DBMS theory MCQs** (keys, normalization, ACID, indexes, joins, warehousing)
- **OA simulator**: 3 SQL questions + 10 MCQs in 30 minutes
- **Interview experiences**: rounds, questions asked and tips from 39 real data-role interviews (Mu Sigma, ZS, Fractal, Tiger, Amazon, Flipkart, Swiggy, Meesho, AmEx, Deloitte and more), summarised with links to the originals
- **Playground** to run any query on the practice tables
- XP, levels, daily streaks, badges and a class leaderboard

Every query runs on a real SQL engine (SQLite) inside your browser and is checked automatically. Each question has 3 hints, a full solution with explanation, a MySQL note, and what the interviewer is actually checking.

Questions are aimed at Data Analyst, Business Analyst, BI Analyst and Data Science roles. Each question is tagged with companies whose job descriptions ask for that skill. All datasets are fictional.

## For students

1. Open the link above (works on laptop and phone; Chrome recommended).
2. Enter your name, roll number, batch, a 4-digit PIN and the class code your mentor gives you.
3. Go world by world. Try without hints first.

Your progress is saved in your browser. To switch devices, use **Profile → Move progress to another device**.
